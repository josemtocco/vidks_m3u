# VidKS → M3U para SS IPTV

Lista gerada automaticamente a cada 6 horas via GitHub Actions.

**URL da lista:**
[raw.githubusercontent.com](https://raw.githubusercontent.com/SEU_USUARIO/vidks-m3u/main/playlist.m3u)

## Como usar no SS IPTV
1. Acesse [ss-iptv.com](https://ss-iptv.com/en/users/playlist) e gere o código de conexão na TV
   (Configurações → Geral → Obter código).
2. Em "External playlists", adicione a URL raw acima.
3. Salve. A TV recarrega a lista e os canais aparecem agrupados por categoria.

Execução manual: aba **Actions → Atualizar playlist M3U → Run workflow**.
